# Конспект: Литералы в C++

## 1. Что такое литерал?

**Литерал** — это фиксированное буквальное значение, записанное непосредственно в тексте программы (буквами и цифрами).

* **Свойства:**
  * Все литералы являются константами, известными на этапе компиляции (**compile-time**).
  * Могут быть зашиты в бинарный код или полностью «исчезнуть» в результате оптимизаций компилятора.
  * Тип литерала определяется его синтаксисом: префиксами, суффиксами, кавычками (`" "`) или апострофами (`' '`).

---

## 2. Простые литералы (bool, nullptr)

* **Логические литералы (`bool`):** `true` (истина) и `false` (ложь).
* **Указательный литерал (`std::nullptr_t`):** `nullptr`.
  * Используется для обнуления указателей и проверки их на `null`.
  * *Рекомендация:* Не использовать старый макрос `NULL` из языка C.

---

## 3. Целочисленные литералы (Integer Literals)

По умолчанию целочисленный литерал имеет тип `int`.

### 3.1. Префиксы систем счисления
* **Десятичная:** без префикса (например, `42`).
* **Восьмеричная:** префикс `0` (например, `075` $= 61_{10}$).
  > ⚠️ **Предупреждение:** Восьмеричный префикс `0` может стать причиной ошибок при форматировании кода нулями (например, `044` станет `36`, а не `44`). Для выравнивания колонок используйте пробелы!
* **Шестнадцатеричная:** префикс `0x` или `0X` (например, `0x41AF` $= 16815_{10}$).
* **Двоичная:** префикс `0b` или `0B` (например, `0b101` $= 5_{10}$).

### 3.2. Суффиксы типов
* `u` / `U` — `unsigned`
* `l` / `L` — `long`
* `ll` / `LL` — `long long`
* *Комбинации:* `UL`, `ULL` (например, `0x41AFull`, `0b1111u`).

### 3.3. Экзотический литерал многосимвольного `int` (C-style)
Записывается в одиночных кавычках из 2–4 ASCII-символов (например, `'abcd'`, `'ZM'`).
* Создает объект типа `int`, упаковывая байты символов (символ справа помещается по младшему адресу).
* *Пример:* `'ab'` имеет значение `0x00006162`.

### 3.4. Задание типа без суффиксов
Для типов `short`, `unsigned short`, `signed char`, `unsigned char` суффиксов нет. Используется явное приведение типов:
* `auto v1 = static_cast<short>(42);` (C++ style)
* `auto v2 = short{42};` (Списковая инициализация)
* `auto v3 = short(42);` (Функциональный стиль)

---

## 4. Вещественные литералы (Floating-point Literals)

По умолчанию вещественный литерал с точкой имеет тип `double`.

### 4.1. Формы записи
1. **Общий (фиксированный) вид:** `5.0`, `5.`, `.5`.
2. **Десятичный экспоненциальный (научный):** символ `e` или `E`.
   * `0.3E-2` $= 0.3 \cdot 10^{-2} = 0.003$
   * `0.3e+2` $= 0.3 \cdot 10^2 = 30$
3. **Шестнадцатеричный экспоненциальный:** префикс `0x`, затем `p` или `P` (степень двойки).
   * Формула: $\text{VALUE}_{16} \cdot 2^{N_{10}}$
   * `0x1.1p0` $= 1.0625$
   * `0x1p-2` $= 0.25$
   * `0xBp2` $= 11 \cdot 2^2 = 44$

### 4.2. Суффиксы
* `f` / `F` — `float` (например, `5.0f`)
* `l` / `L` — `long double` (например, `5.0L`)
* **В C++23 добавлены:**
  * `f16` / `F16` $\rightarrow$ `std::float16_t`
  * `f32` / `F32` $\rightarrow$ `std::float32_t`
  * `f64` / `F64` $\rightarrow$ `std::float64_t`
  * `f128` / `F128` $\rightarrow$ `std::float128_t`

---

## 5. Визуальное разбиение на разряды

Начиная с C++14, численные литералы (`int` и `double`) можно разбивать одиночной кавычкой (апострофом `'`) для удобства чтения:
* `1'000'000`
* `0xa'bc'de`
* `0b001'100'110'011`
* `0.120'03`

> **Ограничение:** Апостроф нельзя ставить рядом с префиксами, суффиксами, десятичной точкой и символом экспоненты.

---

## 6. Символьные и строковые литералы

### 6.1. Символьные литералы
Записываются в одиночных кавычках: `'x'` (тип `char`).
* **Префиксы кодировок:**
  * `L'x'` — `wchar_t`
  * `u8'x'` — `char8_t` (в C++20; до этого — `char`)
  * `u'x'` — `char16_t` (UTF-16)
  * `U'x'` — `char32_t` (UTF-32)

### 6.2. Строковые литералы
Записываются в двойных кавычках: `"abc"` (тип `const char[4]`, неявно включает `'\0'`).
* **Префиксы:** `L"abc"`, `u8"abc"`, `u"abc"`, `U"abc"`.

---

## 7. Сырые строки (Raw String Literals)

Появились в C++11. Позволяют игнорировать эскейп-последовательности (`\n`, `\t`, `\"` и т. д.).

### 7.1. Синтаксис
```cpp
R"(содержимое строки)"
```

### 7.2. Кастомные разделители (Пользовательские скобки)
Чтобы вставить в сырую строку последовательность `)"`, используются пользовательские разделители (до 16 символов из букв, цифр и `_`):
```cpp
R"123(abcd)"efgh)123" // Выведет: abcd)"efgh
```

### 7.3. Области применения
* Вывод многострочного текста (меню, справка).
* Запись регулярных выражений (избавляет от экранирования обратных слешей `\\\\`).

---

## 8. Разбиение строковых литералов

1. **Автоматическое объединение пробелами/переводами строк:**
   ```cpp
   std::cout << "123" "abc" R"(456)"; // Выведет: 123abc456
   ```
2. **Символ склейки `\` (C-style):**
   ```cpp
   std::cout << "123\
   abc\
   456";
   ```
   *(Не рекомендуется к использованию).*

---

## 9. Обработка унарного знака числа

Унарный плюс (`+`) и унарный минус (`-`) **не являются частью литерала**. Это операторы!

**Порядок работы компилятора:**
1. Компилятор определяет тип литерала (например, `42` $\rightarrow$ `int`).
2. Создает безымянный объект со значением `42`.
3. Применяет унарный оператор к объекту как функцию (например, `::operator-(42)`).

> 💡 **Вывод:** Отрицательных литералов в C++ не существует. Выражение `-42` — это применение оператора минус к положительному литералу `42`.
