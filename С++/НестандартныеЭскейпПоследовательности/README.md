# Конспект: Нестандартные (ANSI) эскейп-последовательности в C++

## 1. Что такое нестандартные эскейп-последовательности?

**Нестандартные (ANSI) эскейп-последовательности** — это управляющие наборы символов, отправляемые в поток вывода, которые не отображаются на экране напрямую, а интерпретируются терминалом/консолью как команды переключения настроек.

С их помощью можно управлять:
* Цветом текста и фона (включая RGB-палитру).
* Стилизацией текста (жирный, курсив, подчёркнутый).
* Положением и формой курсора.
* Очисткой строки или всего экрана.
* Рисованием псевдографики (таблиц и рамок).

> ⚠️ **Важное примечание:** Данные ЭП не являются частью стандарта C++ и полностью зависят от поддержки терминалом (работают в Windows Terminal, Visual Studio, Linux/macOS терминалах, OnlineGDB).

---

## 2. Формат управляющего символа Escape

Все управляющие последовательности ANSI начинаются с непечатного символа `Escape` (`ASCII 0x1B` / `2710`):

* Шестнадцатеричная запись: `"\x1b"`
* Восьмеричная запись: `"\33"` или `"\033"` *(часто используется в примерах)*

Управляющие последовательности стиля CSI (Control Sequence Introducer) строятся по схеме:
$$\text{\textbackslash 33[} + \text{параметры} + \text{символ\_команды}$$

## 3. Базовое форматирование и стили текста

Сброс всех настроек форматирования и цвета к значениям по умолчанию:
```cpp
std::cout << "\33[m";   // или "\33[0m"
```

### Стили текста

| Включить | Отключить | Эффект |
| :---: | :---: | :--- |
| `\33[1m` | `\33[22m` | **Жирный (Bold)** |
| `\33[3m` | `\33[23m` | *Курсив (Italic)* |
| `\33[4m` | `\33[24m` | <u>Подчёркнутый (Underline)</u> |

Можно группировать команды через точку с запятой `;`:
```cpp
std::cout << "\33[1;3;4mТекст\33[m"; // Жирный, курсив и подчёркнутый одновременно
```

## 4. Управление цветом

### 4.1. Стандартная палитра (16 цветов)

* **Цвет текста (Foreground):** `\33[3Nm` (тёмный) или `\33[9Nm` (яркий)
* **Цвет фона (Background):** `\33[4Nm` (тёмный) или `\33[10Nm` (яркий)

Где `N` — индекс цвета от 0 до 7:

| N | Цвет | N | Цвет |
| :---: | :--- | :---: | :--- |
| **0** | Чёрный | **4** | Синий |
| **1** | Красный | **5** | Пурпурный (Magenta) |
| **2** | Зелёный | **6** | Бирюзовый (Cyan) |
| **3** | Жёлтый | **7** | Белый |

### 4.2. Произвольный цвет RGB (24-bit TrueColor)

Позволяет задавать точный цвет по составляющим $R, G, B \in [0, 255]$:

* **Цвет текста:** `"\33[38;2;R;G;Bm"`
* **Цвет фона:** `"\33[48;2;R;G;Bm"`

```cpp
// Установка цвета текста R=255, G=128, B=0 (оранжевый)
std::cout << "\33[38;2;255;128;0m Текст \33[m";
```

### 4.3. Инверсия цвета

Меняет местами цвет текста и цвет фона:
* `\33[7m` — включить инверсию.
* `\33[27m` — отключить инверсию.

## 5. Управление позицией и формой курсора

Индексация строк и колонок в терминале начинается с **1** (верхний левый угол — `1;1`).

### Относительное перемещение

| Команда | Действие |
| :--- | :--- |
| `\33[NA` | Сдвиг курсора **вверх** на $N$ строк |
| `\33[NB` | Сдвиг курсора **вниз** на $N$ строк |
| `\33[NC` | Сдвиг курсора **вправо** на $N$ позиций |
| `\33[ND` | Сдвиг курсора **влево** на $N$ позиций |

*(Если $N$ не указано, берется 1)*

### Абсолютное перемещение

| Команда | Действие |
| :--- | :--- |
| `\33[Yd` | Переместить на строку $Y$ |
| `\33[XG` | Переместить на колонку $X$ |
| `\33[Y;XH` *(или `\33[Y;Xf`)* | Переместить в координаты (строка $Y$, колонка $X$) |

### Сохранение и восстановление позиции

* `\33[s` — сохранить текущее положение курсора.
* `\33[u` — восстановить сохранённую позицию.

### Видимость и форма курсора

* `\33[?25l` — скрыть курсор.
* `\33[?25h` — показать курсор.

**Форма курсора (`\33[N q`):**
* `\33[0 q` — по умолчанию
* `\33[1 q` / `\33[2 q` — мигающий / статичный прямоугольник ▯
* `\33[3 q` / `\33[4 q` — мигающее / статичное подчёркивание \_
* `\33[5 q` / `\33[6 q` — мигающая / статичная вертикальная черта \|

## 6. Очистка экрана и строк

### Очистка строки (`\33[NK`)
* `\33[0K` — очистить от курсора до конца строки.
* `\33[1K` — очистить от начала строки до курсора.
* `\33[2K` — очистить всю строку.

### Очистка консоли (`\33[NJ`)
* `\33[0J` — очистить от курсора до правого нижнего угла.
* `\33[1J` — очистить от верхнего левого угла до курсора.
* `\33[2J` — очистить весь экран.

> 💡 **Полный сброс экрана:** Чтобы полностью очистить экран и вернуть курсор в начало, используйте связку:
> ```cpp
> std::cout << "\33[2J\33[;H";
> ```

## 7. Рисование псевдографики (рамки и таблицы)

Включение альтернативного набора символов DEC Special Graphics:
* `\33(0` — включить режим псевдографики (для символов с ASCII-кодами `0x59`–`0x7E`).
* `\33(B` — вернуться в обычный режим.

### Сопоставление символов в режиме `\33(0`:

| Символ | Графика | Описание |
| :---: | :---: | :--- |
| `l` / `k` | `┌` / `┐` | Левый верхний / правый верхний угол |
| `m` / `j` | `└` / `┘` | Левый нижний / правый нижний угол |
| `q` / `x` | `─` / `│` | Горизонтальная / вертикальная линия |
| `t` / `u` | `├` / `┤` | Левый / правый соединитель |
| `v` / `w` | `┴` / `┬` | Нижний / верхний соединитель |
| `n` | `┼` | Крестовина |
| `a` | `▒` | Заливка (штриховка) |

### Пример отрисовки рамки:
```cpp
#include <iostream>

int main() {
    std::cout << "\33(0"; // Включаем режим псевдографики
    std::cout << "lqqk\n";
    std::cout << "x  x\n";
    std::cout << "mqqj\n";
    std::cout << "\33(B"; // Возвращаем обычный режим
    return 0;
}
```
**Результат:**
```text
┌──┐
│  │
└──┘
```
