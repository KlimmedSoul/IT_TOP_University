## 1. Точка входа `main()` и структура программы

Любая программа на C++ должна содержать **точку входа** — функцию `main()`.

Функция `main()` не вызывается программистом вручную. Она вызывается операционной системой при запуске программы.

### Стандартный вариант без аргументов

```cpp
int main()
{
	return 0;
}
```

Функция `main()` возвращает значение типа `int`.

Возвращаемое значение `0` означает успешное завершение программы.

### Вариант с аргументами командной строки

```cpp
int main(int count, char** arguments)
{
	// arguments[0] — путь к самой программе
	// arguments[1] ... arguments[count - 1] — переданные аргументы

	return 0;
}
```

Где:

- `count` — количество аргументов командной строки;
- `arguments` — массив строк с аргументами;
- `arguments[0]` — путь или имя запущенной программы;
- `arguments[1] ... arguments[count - 1]` — переданные программе аргументы.

> **Важно:** модифицировать массив `arguments` запрещено стандартом.

### Директивы препроцессора

Директивы препроцессора начинаются с символа `#`.

Например:

```cpp
#include <iostream>
```

Директива `#include` подключает содержимое заголовочного файла перед этапом компиляции.

В конце строк с директивами препроцессора **точка с запятой `;` не ставится**.

## 2. Правила создания идентификаторов

**Идентификатор** — это имя переменной, функции, структуры или другого объекта программы.

### Разрешённые символы

В идентификаторах могут использоваться:

- латинские буквы `a-z`, `A-Z`;
- цифры `0-9`;
- знак подчёркивания `_`.

Регистр имеет значение:

```cpp
int value;
int Value;
```

`value` и `Value` — это два разных идентификатора.

### Начало идентификатора

Идентификатор **не может начинаться с цифры**.

Неправильно:

```cpp
int 1a;
```

Правильно:

```cpp
int a1;
```

### Ключевые слова

Нельзя использовать в качестве идентификаторов ключевые слова языка C++.

Например:

```cpp
int double;
```

Такой код вызовет ошибку компиляции, поскольку `double` является ключевым словом.

### Зарезервированные идентификаторы

Следует избегать использования идентификаторов, зарезервированных стандартом C++.

В частности, не следует использовать:

```cpp
int my__var;
```

и:

```cpp
int _Var;
```

Особенно важно избегать имён, начинающихся с `_` или содержащих `__`, поскольку некоторые такие имена зарезервированы для реализации языка и стандартной библиотеки.

## 3. Фундаментальные типы данных

Фундаментальные типы используются для хранения различных видов данных.

| Тип | Размер* | Описание |
|---|---:|---|
| `bool` | 1 байт | `true` или `false` |
| `char` | 1 байт | Символ |
| `short` | 2 байта | Целое число |
| `unsigned short` | 2 байта | Беззнаковое целое число |
| `int` | 4 байта | Целое число |
| `unsigned int` | 4 байта | Беззнаковое целое число |
| `long long` | 8 байт | Большое целое число |
| `float` | 4 байта | Вещественное число |
| `double` | 8 байт | Вещественное число повышенной точности |

\* Размеры указаны для распространённых платформ и компиляторов. Стандарт C++ не гарантирует, что конкретный тип всегда занимает именно указанное количество байт.

### `bool`

Хранит логическое значение:

```cpp
bool isReady = true;
bool isFinished = false;
```

В логическом контексте значения соответствуют:

- `true` — `1`;
- `false` — `0`.

### `char`

Используется для хранения одного символа:

```cpp
char symbol = 'A';
```

Размер `char` всегда составляет **1 байт**, однако количество бит в байте определяется реализацией. На современных распространённых системах это 8 бит.

### `short`

Обычно занимает 2 байта:

```cpp
short number = 1000;
```

Для распространённого 16-битного `short` диапазон составляет:

```text
-32 768 ... 32 767
```

### `unsigned short`

Беззнаковый вариант `short`:

```cpp
unsigned short number = 50000;
```

Для 16-битного типа диапазон:

```text
0 ... 65 535
```

### `int`

Основной тип для хранения целых чисел:

```cpp
int age = 25;
```

Для 32-битного `int` диапазон:

```text
-2 147 483 648 ... 2 147 483 647
```

### `unsigned int`

Беззнаковый вариант `int`:

```cpp
unsigned int count = 100;
```

Для 32-битного типа диапазон:

```text
0 ... 4 294 967 295
```

### `long long`

Используется для хранения больших целых чисел:

```cpp
long long population = 8000000000LL;
```

На распространённых платформах занимает 8 байт.

### `float`

Используется для хранения вещественных чисел:

```cpp
float temperature = 36.6f;
```

Обычно обеспечивает около 7 значащих цифр точности.

### `double`

Вещественный тип с большей точностью:

```cpp
double pi = 3.141592653589793;
```

Обычно обеспечивает около 15–17 значащих цифр точности.

## 4. Переполнение числовых типов

### Знаковые типы

Переполнение знаковых целочисленных типов приводит к **неопределённому поведению (Undefined Behavior, UB)**.

Например:

```cpp
short value = 32767;
value++;
```

Для стандартного 16-битного `short` результат не следует считать гарантированным стандартом C++.

### Беззнаковые типы

Для беззнаковых целых чисел используется арифметика по модулю `2^N`, где `N` — количество битов типа.

Например, для 8-битного `unsigned char`:

```text
255 + 1 → 0
```

То есть значение циклически переходит через границу диапазона.

## 5. Переменные и их квалификаторы

### Инициализация переменных

Переменную рекомендуется инициализировать сразу при создании.

Предпочтительный вариант:

```cpp
int x{};
```

В данном случае `x` получает значение `0`.

Также можно использовать:

```cpp
int x = 0;
```

Неинициализированная локальная переменная может содержать неопределённое значение.

Например:

```cpp
int x;
```

Использование такой переменной до корректной инициализации может привести к неопределённому поведению.

### `const`

Ключевое слово `const` делает объект неизменяемым после инициализации.

Например:

```cpp
const int MAX_USERS = 100;
```

После создания изменить значение нельзя:

```cpp
MAX_USERS = 200; // ошибка
```

`const`-переменная должна быть инициализирована при создании.

Также можно использовать единый стиль с фигурными скобками:

```cpp
const int MAX_USERS{100};
```

### `volatile`

Ключевое слово `volatile` сообщает компилятору, что значение объекта может изменяться способом, который не должен быть устранён или объединён обычными оптимизациями.

Пример:

```cpp
volatile int value;
```

`volatile` может встречаться при работе с аппаратными регистрами и некоторыми низкоуровневыми механизмами.

> **Важно:** `volatile` не является средством синхронизации потоков и не делает операции над переменной атомарными.

## 6. Потоки ввода и вывода

Для работы с консольным вводом и выводом часто используется заголовочный файл:

```cpp
#include <iostream>
```

Основные объекты:

- `std::cout` — вывод;
- `std::cin` — ввод.

---

### `std::cout`

`std::cout` используется для вывода информации в стандартный поток вывода.

Для передачи данных используется оператор `<<`:

```cpp
std::cout << "Hello, World!";
```

Можно выводить несколько значений:

```cpp
int age{20};

std::cout << "Age: " << age << '\n';
```

Для перевода строки можно использовать:

```cpp
'\n'
```

или:

```cpp
std::endl
```

При этом `std::endl` дополнительно выполняет сброс буфера, поэтому в обычном выводе часто предпочтительнее использовать `'\n'`.

Принудительно сбросить буфер можно с помощью:

```cpp
std::flush
```

Например:

```cpp
std::cout << "Hello" << std::flush;
```

---

### `std::cin`

`std::cin` используется для получения данных из стандартного потока ввода.

Оператор:

```cpp
>>
```

извлекает данные из потока.

Пример:

```cpp
int age{};

std::cin >> age;
```

При использовании `operator>>` для обычных типов ведущие пробельные символы, такие как пробелы и переводы строк, пропускаются.

---

### `std::cin.get()`

Метод `get()` позволяет прочитать один символ, включая пробелы и переводы строки.

```cpp
char symbol{};

std::cin.get(symbol);
```

Например, если пользователь введёт:

```text
A
```

то `symbol` получит символ `'A'`.

---

### `std::getline()`

`std::getline()` используется для считывания целой строки.

```cpp
#include <iostream>
#include <string>

int main()
{
	std::string name{};

	std::getline(std::cin, name);

	std::cout << name << '\n';

	return 0;
}
```

В отличие от:

```cpp
std::cin >> name;
```

`std::getline()` считывает строку целиком, включая пробелы.

Например, ввод:

```text
Ivan Petrov
```

будет полностью записан в переменную `name`.

## 7. Ошибки ввода

При попытке считать число, если пользователь ввёл некорректные данные, поток может перейти в состояние ошибки.

Например:

```cpp
int number{};

std::cin >> number;
```

Если пользователь введёт:

```text
hello
```

операция чтения завершится ошибкой.

Проверить состояние потока можно:

```cpp
if (!std::cin)
{
	// произошла ошибка ввода
}
```

### Очистка состояния ошибки

Для сброса флага ошибки используется:

```cpp
std::cin.clear();
```

После этого некорректные данные всё ещё остаются во входном буфере. Их необходимо удалить:

```cpp
std::cin.ignore(1000, '\n');
```

Полный пример:

```cpp
if (!std::cin)
{
	std::cin.clear();
	std::cin.ignore(1000, '\n');
}
```

После этого поток можно использовать снова.

# 8. Требования к оформлению домашних заданий

При выполнении домашних заданий необходимо соблюдать требования преподавателя.

## Стандарт языка

Используется:

```text
C++17
```

---

## Запрет `using namespace std`

Запрещено использовать:

```cpp
using namespace std;
```

Вместо этого необходимо явно указывать пространство имён:

```cpp
std::cout
std::cin
std::string
```

Например:

```cpp
#include <iostream>

int main()
{
	std::cout << "Hello, World!\n";

	return 0;
}
```

---

## Расположение фигурных скобок

Открывающая фигурная скобка ставится **на новой строке**.

Правильно:

```cpp
int main()
{
	std::cout << "Hello";
}
```

Не рекомендуется:

```cpp
int main() {
	std::cout << "Hello";
}
```

Вложенные блоки оформляются с использованием **TAB** для отступов:

```cpp
int main()
{
	int number{};

	if (number == 0)
	{
		std::cout << "Zero\n";
	}

	return 0;
}
```

---

## Комментарий с условием задачи

В самом начале каждого файла `main.cpp` необходимо размещать многострочный комментарий с условием задачи:

```cpp
/*
	Условие задачи:

	Здесь размещается полный текст условия.
*/
```

После комментария располагается исходный код программы.

---

## Сдача домашних заданий

Каждая задача должна предоставляться в виде **отдельной ссылки** через кнопку **Share** на платформе **OnlineGDB**.

При создании ссылки необходимо установить срок хранения:

```text
Month
```

Таким образом, для каждой выполненной задачи должна быть создана отдельная ссылка на соответствующий проект в OnlineGDB.

# 9. Минимальный шаблон программы

С учётом требований курса базовый файл `main.cpp` может выглядеть следующим образом:

```cpp
/*
	Условие задачи:

	Здесь размещается условие задачи.
*/

#include <iostream>

int main()
{
	std::cout << "Hello, World!\n";

	return 0;
}
```

# 10. Краткая памятка

| Что | Правило |
|---|---|
| Стандарт | **C++17** |
| Точка входа | `int main()` |
| Пространство имён | Не использовать `using namespace std;` |
| Вывод | `std::cout` |
| Ввод | `std::cin` |
| Ввод строки | `std::getline()` |
| Чтение символа | `std::cin.get()` |
| Инициализация | Предпочтительно `int x{};` |

| Скобки | На новой строке |
| Отступы | TAB |
| Условие задачи | В начале каждого `main.cpp` |
| Сдача | Отдельная ссылка OnlineGDB для каждой задачи |
| Срок ссылки | `Month` |
