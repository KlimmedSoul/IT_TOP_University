# Объявление и определение сущностей в C++

В языке C++ для написания программ используется различный набор сущностей: переменные, перечисления (`enum`), классы (`class`), структуры (`struct`), функции и другие. Каждую сущность можно **объявить** (*declare*) и **определить** (*define*). Часто определение одновременно выступает и в роли объявления.

---

## 1. Объявление (Declaration)

**Объявление** — заявляет компилятору о наличии нового идентификатора (имени), а также указывет его роль (переменная, новый тип, функция и т.д.).

### Ключевые особенности объявления:
* **Не содержит** полного описания сущности (неизвестен точный размер объекта в байтах, реализация функции и т.д.).
* Заканчивается точкой с запятой `;`.
* **Может повторяться сколько угодно раз** для одной и той же сущности в программе.
* Позволяет использовать имя сущности в некоторых других объявлениях или определениях до того, как появится полное определение.

### Примеры объявлений:

1. **Классы и структуры (Forward Declaration):**
   ```cpp
   class A;  // Объявление класса A
   struct B; // Объявление структуры B
   ```
   *Компилятор узнает, что `A` и `B` — это типы. Их уже можно использовать для создания указателей/ссылок или в параметрах функций.*

2. **Функции (Прототип функции):**
   ```cpp
   long func(int, char); // Объявление функции
   ```
   *Компилятор знает тип возвращаемого значения (`long`) и типы аргументов (`int`, `char`). Этого достаточно для вызова функции, но компилятор не сможет собрать исполняемый модуль без её тела.*

3. **Глобальные переменные:**
   ```cpp
   extern int a; // Объявление глобальной переменной
   extern int a; // Повторное объявление разрешено
   ```
   > **Важно:** Локальные переменные нельзя просто объявить — их можно только определить (что одновременно выступает и объявлением).

---

## 2. Определение (Definition)

**Определение** — это полное описание всех свойств и размеров сущности (размер класса, набор его полей и методов, тело функции, выделение памяти под переменную).

### Ключевые особенности определения:
* **Правило одного определения (One Definition Rule / ODR):** Для одной сущности разрешено только **одно** определение в одной области видимости.
* Нарушение ODR приводит к ошибкам компиляции/линковки или к **неопределенному Behaviour (Undefined Behavior)**.
* Любое определение **одновременно является и объявлением**, если эта сущность не была объявлена ранее.

### Примеры определений:

1. **Определение класса:**
   ```cpp
   class A 
   {
       // Поля и методы класса
   }; // Теперь известен размер sizeof(A) и структура
   ```

2. **Определение функции:**
   ```cpp
   int func(int x, char c) 
   {
       return 42; // Тело функции
   }
   ```

3. **Определение переменных:**
   ```cpp
   int a;      // Определение (и объявление) глобальной переменной
   int main() 
   {
       int b;  // Определение (и объявление) локальной переменной
       A obj;  // Определение объекта типа A
   }
   ```

## 3. Сводная таблица и ключевые выводы

| Понятие | Что делает? | Количество повторений | Результат для компилятора |
| :--- | :--- | :--- | :--- |
| **Объявление** (*Declaration*) | Вводит имя, его тип и роль. | Сколько угодно раз | Знание о существовании имени и его сигнатуре/типе. |
| **Определение** (*Definition*) | Содержит полное описание (тело, поля, память). | Ровно 1 раз (ODR) | Знание размера, внутренней структуры и исполняемого кода. |

### Главные тезисы:
1. **Объявление** вводит новое имя сущности, её тип и роль.
2. **Определение** полностью описывает сущность.
3. Если определение встречается раньше объявления, оно выполняет роль **и определения, и объявления**.
4. В обиходной речи фраза *"объявляем переменную"* чаще всего подразумевает её *определение* (например, `int x;`).

## 4. Ответ на практическое задание

**Задание:** *Приведите пример объявления и определения глобальной переменной. Покажите возможность использования этой переменной до её определения.*

```cpp
#include <iostream>

// 1. Объявление глобальной переменной (компилятор знает, что 'a' существует)
extern int a; 

void printA() 
{
    // Использование переменной 'a' ДО её определения
    std::cout << "Значение a: " << a << std::endl; 
}

// 2. Определение глобальной переменной (выделяется память)
int a = 100; 

int main() 
{
    printA(); // Выведет: Значение a: 100
    
    a = 200;  // Изменение значения
    printA(); // Выведет: Значение a: 200
    
    return 0;
}
```
