# Константа времени компиляции (Compile-Time Constant) в C++

## 1. Основные понятия

* **Константа времени компиляции (core constant expression)** — это выражение, значение которого полностью и гарантированно вычисляется на этапе компиляции (**compile-time**).
* **Поведение во время выполнения (run-time):** В скомпилированном бинарном файле результат вычисления уже представлен в виде готового числа или набора данных. На этапе выполнения процессору не нужно тратить такты на его вычисление — значение просто загружается в регистр или читается из памяти.

---

## 2. Что может быть compile-time выражением?

1. **`constexpr`-переменные.**
2. **Оператор `sizeof(...)`** и выражения внутри него.
3. **Литералы** (например, `42`, `'a'`, `3.14`).
4. **Перечислимый тип** (`enum`, `enum class`).
5. **Значения, возвращаемые из `constexpr`- и `consteval`-функций.**
6. **Некоторые пользовательские типы** (соответствующие требованиям `LiteralType`).

---

## 3. `constexpr`-переменные

* Переменная, объявленная с ключевым словом `constexpr`, **обязана** быть инициализирована прямо при объявлении.
* Инициализатором должно выступать другое `constexpr`-выражение.

### Отличие `constexpr` от `const`
* **`const`:** Указывает на то, что значение переменной нельзя изменять после инициализации. Компилятор *может* вычислить её на этапе компиляции (при включенных оптимизациях), но также имеет право отложить вычисление на runtime.
* **`constexpr`:** Гарантирует (**обязывает** компилятор), что выражение будет вычислено strictly на этапе компиляции.

```cpp
// Вычисление может быть отложено на runtime
const int N1 = 42;
int N2 = 42 + N1;

// Гарантированное вычисление на этапе компиляции
constexpr int N1 = 42;
constexpr int N2 = 42 + N1;
```

---

## 4. Оператор `sizeof()`

* Оператор `sizeof` возвращает размер типа, объекта или выражения в байтах.
* **Главное свойство:** Оператор `sizeof` и всё, что находится внутри его скобок, **всегда является `constexpr`-выражением**.
* Выражение внутри `sizeof(...)` **не вычисляется в runtime**. Оценивается только тип итогового результата (Unevaluated operand).

### Пример поведения:
```cpp
#include <iostream>

int main() {
    // Выражение (std::cout << '\n' << 42) НЕ выполняется!
    // Печатается только размер типа std::ostream в байтах.
    std::cout << sizeof(std::cout << '\n' << 42); 
}
```
*Данный код эквивалентен:*
```cpp
std::cout << sizeof(std::ostream);
```

## 5. Особенности применения

### Вещественные числа (`float`, `double`)
Использование операций с плавающей точкой в `constexpr` разрешено, но **не рекомендуется** без особой необходимости:
* Алгоритмы и точность вычислений с плавающей точкой на этапе компиляции (внутри самого компилятора) могут отличаться от арифметических инструкций CPU, выполняемых в runtime.
* Из-за этого вычисленное в compile-time значение `double` может незначительно отличаться от результата, вычисленного в run-time.

```cpp
constexpr double A = 1.0 / 3.0; // Compile-time (например: 0.33333333333300003)

double x = 1.0;
double y = 3.0;
double B = x / y;               // Run-time (например: 0.333333333334)
```

### Неопределенное поведение (UB)
Внутри `constexpr`-выражений **не допускается неопределенное поведение (Undefined Behavior)**. Если в ходе compile-time вычислений возникает UB (например, деление на ноль или выход за пределы массива), программа **не скомпилируется**.

## 6. Разбор практического примера

Рассмотрим пример кода из презентации:

```cpp
#include <iostream>

int main()
{
    constexpr int N1 = 0;
    constexpr int A = N1;      // OK: constexpr-переменная
    
    std::cout << sizeof(N1) << '\n'; // OK: sizeof(int)

    const int N2{};
    std::cin >> N2;            // ОШИБКА КОМПИЛЯЦИИ: N2 объявлена как const, 
                               // её значение нельзя изменять через std::cin

    int N3{};
    std::cin >> N3;            // OK: обычная переменная
    
    std::cout << sizeof(N3) << '\n';   // OK: sizeof(int)
    std::cout << sizeof(1 + A) << '\n'; // OK: sizeof(int)
    std::cout << sizeof(1 + 3) << '\n'; // OK: sizeof(int)
}
```

### Анализ ошибок и особенностей:
1. **Ошибка:** `std::cin >> N2;` — приводит к ошибке компиляции, так как `N2` имеет квалификатор `const`.
2. **`constexpr`-объекты:** `N1`, `A`.
3. **`constexpr`-выражения:** Все вызовы `sizeof(...)`, выражения `1 + A`, `1 + 3`, а также литералы `0`, `1`, `3`.
