# C++: ввод и вывод данных

## 1. Стандартные потоки ввода-вывода

При запуске процесса операционная система создаёт три стандартных потока:

| Поток | Дескриптор | Назначение |
|---|---:|---|
| `stdin` | `0` | Ввод данных |
| `stdout` | `1` | Вывод данных |
| `stderr` | `2` | Вывод сообщений об ошибках |

Обычно:

- `stdin` получает данные с клавиатуры;
- `stdout` выводит данные на экран;
- `stderr` используется для сообщений об ошибках.

Потоки можно перенаправлять на файлы, устройства или другие процессы.

---

## 2. Перенаправление потоков

Перенаправление часто выполняется через командную строку.

### Вывод в файл

```bash
a.out > output.txt
```

`>` создаёт новый файл либо очищает существующий, после чего записывает в него вывод программы.

### Дописывание в файл

```bash
a.out >> output.txt
```

`>>` не очищает файл, а дописывает данные в его конец.

### Ввод из файла

```bash
a.out < input.txt
```

Входные данные программы берутся из `input.txt`.

### Одновременный ввод и вывод

```bash
a.out < input.txt > output.txt
```

Данные читаются из `input.txt`, а вывод записывается в `output.txt`.

### Конвейер (`pipeline`)

В Linux символ `|` позволяет передавать вывод одного процесса на вход другого:

```bash
процесс1 | процесс2 | процесс3
```

Например:

```bash
a.out | grep "abc" > output.txt
```

`grep` получает данные от `a.out`, оставляет строки, содержащие `abc`, и записывает результат в файл.

## 3. Стандартные потоки в C++

Для работы со стандартными потоками используется:

```cpp
#include <iostream>
```

В пространстве имён `std` определены основные объекты:

```cpp
namespace std
{
    istream cin;
    ostream cout;
    ostream cerr;
    ostream clog;
}
```

### Основные объекты

| Объект | Тип | Назначение |
|---|---|---|
| `std::cin` | `std::istream` | Ввод с клавиатуры |
| `std::cout` | `std::ostream` | Вывод на экран |
| `std::cerr` | `std::ostream` | Вывод ошибок без буферизации |
| `std::clog` | `std::ostream` | Буферизированный вывод в `stderr` |

`std::cout` использует буферизированный вывод, а `std::cerr` — нет.

---

## 4. Буферизация

**Буфер** — дополнительный контейнер в памяти, в котором временно накапливаются символы перед отправкой в поток.

Буферизация нужна, потому что отдельная операция вывода является относительно дорогой для процессора. Вместо отправки каждого символа отдельно данные сначала накапливаются, а затем отправляются группой.

Буфер может быть отправлен в поток при:

- переполнении буфера;
- выводе `\n`;
- вызове `flush()`.

### Важный недостаток

Если программа аварийно завершится до отправки буфера, находящиеся в нём данные могут потеряться.

Поэтому `std::cerr` не использует буферизацию: сообщения об ошибках важно вывести даже при аварийном завершении программы.

# 5. Перевод строки

Для перехода на новую строку используется escape-последовательность:

```cpp
\n
```

Это **один символ**, а не два отдельных символа. Его код — `0x0A`.

Пример:

```cpp
std::cout << "Hello\nWorld";
```

Результат:

```text
Hello
World
```

Можно использовать несколько переводов строки:

```cpp
std::cout << "\n\nHello\n";
```

# 6. Вывод на экран: `std::cout`

Для вывода используется объект:

```cpp
std::cout
```

и оператор:

```cpp
<<
```

Пример:

```cpp
#include <iostream>

int main()
{
    std::cout << 42;
    std::cout << "\n";

    int N = 123;
    std::cout << "значение = " << N << "\n";
}
```

Оператор `<<` можно использовать последовательно для вывода нескольких значений:

```cpp
std::cout << A << B << C;
```

То есть значения выводятся последовательно, «трамвайчиком».

### Вывод `char`

Для типов:

```cpp
char
signed char
unsigned char
```

оператор `<<` интерпретирует значение как код символа ASCII.

Например:

```cpp
char c = 70;
std::cout << c;
```

выведет:

```text
F
```

Поскольку код `70` соответствует символу `F`.

Также можно сразу использовать символьный литерал:

```cpp
c = 'F';
```

# 7. Ввод с клавиатуры: `std::cin`

Для ввода используется:

```cpp
std::cin
```

Основные способы:

```cpp
std::cin >> ...
std::cin.get(...)
std::getline(...)
```

---

# 8. Ввод чисел оператором `>>`

Пример:

```cpp
#include <iostream>

int main()
{
    std::cout << "Введите целое число: ";

    int N{};
    std::cin >> N;

    std::cout << "Введите вещественное число: ";

    double D{};
    std::cin >> D;

    std::cout << "N=" << N << "\n";
    std::cout << "D=" << D << "\n";
}
```

Оператор:

```cpp
>>
```

извлекает данные из входного потока и помещает их в переменную.

### Инициализация переменных

Перед вводом рекомендуется инициализировать переменную:

```cpp
int N = 0;
```

или:

```cpp
int N{};
```

Это важно, поскольку в некоторых ситуациях поток может не изменить значение переменной.

### `Enter`

При нажатии `Enter` во входной поток попадает символ перевода строки.

Поэтому при обычном вводе через `>>` не требуется дополнительно выводить `\n` для самого факта нажатия `Enter`.

---

# 9. Ввод одного символа через `>>`

```cpp
char ch{};
std::cin >> ch;
```

Особенность:

> `>>` игнорирует пробельные символы.

То есть пропускаются:

- пробелы;
- переводы строк;
- другие пробельные символы.

После этого считывается первый непробельный символ.

Например:

```cpp
char ch{};
std::cin >> ch;
std::cout << ch;
```

Если пользователь вводит пробел, непосредственно считать пробел таким способом невозможно — он будет пропущен.

---

# 10. Ввод одного символа через `std::cin.get()`

Другой способ:

```cpp
char ch{};
std::cin.get(ch);
```

В отличие от `>>`, метод `get()` считывает **любой символ**, включая пробел и перевод строки.

```cpp
#include <iostream>

int main()
{
    char ch{};
    std::cin.get(ch);
    std::cout << ch;
}
```

Таким образом:

| Способ | Пробелы |
|---|---|
| `std::cin >> ch` | Игнорируются |
| `std::cin.get(ch)` | Считываются |



---

# 11. Ввод строки без пробелов: `std::string` + `>>`

Для хранения строки используется:

```cpp
#include <string>
std::string
```

Пример:

```cpp
std::string s;

std::cin >> s;
```

`>>`:

1. игнорирует начальные пробельные символы;
2. считывает непробельные символы;
3. останавливается на пробеле или конце потока;
4. завершающий пробельный символ остаётся во входном потоке.

Например, если введено:

```text
111 222 333
```

три последовательных операции:

```cpp
std::cin >> s;
std::cin >> s;
std::cin >> s;
```

получат соответственно:

```text
111
222
333
```

Следовательно, `>>` **не подходит для чтения строки, содержащей пробелы**.

---

# 12. Ввод строки с пробелами: `std::getline()`

Для чтения всей строки используется:

```cpp
std::getline(std::cin, s);
```

По умолчанию функция считывает символы до:

```cpp
\n
```

При этом сам разделитель `\n` в строку не попадает и удаляется из потока.

Пример:

```cpp
#include <iostream>
#include <string>

int main()
{
    std::string s;

    std::getline(std::cin, s);

    std::cout << s;
}
```

Если пользователь вводит:

```text
111 222 333
```

в `s` попадёт вся строка:

```text
111 222 333
```

### Собственный разделитель

Можно указать другой разделитель:

```cpp
std::getline(std::cin, s, ',');
```

Теперь чтение прекращается при встрече `,`.

Например:

```text
111,222
```

считает:

```text
111
```

а `,` будет удалена из потока.

---

# 13. `std::cin.ignore()`

Метод `ignore()` позволяет удалить символы из начала входного потока.

### Один символ

```cpp
std::cin.ignore();
```

Удаляет один символ.

### До 10 символов

```cpp
std::cin.ignore(10);
```

Удаляет максимум 10 символов либо до конца потока.

### До определённого разделителя

```cpp
std::cin.ignore(10, '\n');
```

Удаляет максимум 10 символов до `\n`, причём сам `\n` также удаляется.

---

## Типичная проблема `cin >>` + `getline()`

Например:

```cpp
int n{};
std::string s;

std::cin >> n;
std::getline(std::cin, s);
```

После ввода числа пользователь нажимает `Enter`.

`std::cin >> n` считывает число, но перевод строки `\n` остаётся во входном потоке.

Поэтому следующий `getline()` может сразу встретить этот `\n` и получить пустую строку.

Решение:

```cpp
std::cin >> n;
std::cin.ignore();
std::getline(std::cin, s);
```

Таким образом, `ignore()` удаляет оставшийся перевод строки.

# 14. Обработка ошибок ввода

Поток может перейти в состояние ошибки.

Например, программа ожидает:

```cpp
int n{};
std::cin >> n;
```

а пользователь вводит:

```text
*
```

Такой ввод не соответствует ожидаемому `int`.

После ошибки:

- устанавливается флаг ошибки;
- неправильный символ остаётся во входном потоке;
- последующие операции ввода также не работают;
- переменная не получает новое корректное значение.

Проверить состояние можно:

```cpp
if (!std::cin)
{
    std::cout << "error\n";
}
```

# 15. Восстановление потока после ошибки

Для восстановления необходимо выполнить **два действия**:

1. Сбросить флаги ошибки с помощью `clear()`.
2. Удалить неправильные символы из входного потока.

Пример:

```cpp
if (!std::cin)
{
    std::cout << "error\n";

    std::cin.clear();
    std::cin.ignore(1000, '\n');
}
```

Здесь:

```cpp
std::cin.clear();
```

сбрасывает состояние ошибки.

А:

```cpp
std::cin.ignore(1000, '\n');
```

удаляет оставшийся неправильный ввод до перевода строки включительно.

### Главное

```cpp
clear()
```

**не удаляет неправильный символ из потока.**

Поэтому одного `clear()` недостаточно.

# 16. `std::cin.unget()`

Метод:

```cpp
std::cin.unget();
```

возвращает в поток **последний считанный символ**.

Пример:

```cpp
char ch{};

std::cin >> ch;
std::cout << ch << "\n";

std::cin.unget();

std::cin >> ch;
std::cout << ch << "\n";
```

Один и тот же символ будет считан повторно.

`unget()` полезен при разборе входных данных, когда символ был извлечён для проверки, но затем должен снова участвовать в алгоритме обработки.

---

# 17. `std::cin.putback()`

Метод:

```cpp
std::cin.putback('x');
```

помещает указанный символ обратно в начало входного потока.

Например:

```cpp
std::cin.putback('a');
std::cin.putback('b');
std::cin.putback('c');
```

Следующее чтение получит символы в порядке:

```text
cba
```

Метод может использоваться для тестирования: вместо постоянного ввода данных с клавиатуры можно заранее поместить необходимые символы в поток.

# 19. Что важно запомнить

### Вывод

```cpp
std::cout << value;
```

Несколько значений:

```cpp
std::cout << A << B << C;
```

Перевод строки:

```cpp
std::cout << "\n";
```

### Ввод

Число:

```cpp
int n{};
std::cin >> n;
```

Слово/строка без пробелов:

```cpp
std::string s;
std::cin >> s;
```

Строка с пробелами:

```cpp
std::getline(std::cin, s);
```

Один любой символ:

```cpp
char ch{};
std::cin.get(ch);
```

### После ошибки

```cpp
std::cin.clear();
std::cin.ignore(1000, '\n');
```

### Главное различие

```text
cin >>       → пропускает пробелы
cin.get()    → читает и пробелы
getline()    → читает всю строку до разделителя
```

В конце занятия предложены три задачи:

### Задача 1. Перевод секунд во время

Пользователь вводит количество секунд в:

```cpp
int total_seconds
```

Нужно получить:

- часы;

```text
1000 → 0 : 16 : 40
```

```text
12
45
```

Пользователь вводит:

- сумму вклада в рублях;
- процент годовых.

Нужно определить сумму денег, которую банк выплачивает вкладчику каждый месяц.

## Итоговая схема

```text
                    Ввод и вывод C++
                           │
          ┌────────────────┴────────────────┐
          │                                 │
        Ввод                              Вывод
          │                                 │
      std::cin                           std::cout
          │                                 │
   ┌──────┼─────────┐                       │
   │      │         │                       │
  >>    get()   getline()                  <<
   │      │         │                       │
 числа   символ   строка              значения
 слово   любой    с пробелами
```

Главная идея занятия: **поток — это последовательность данных, с которой программа может читать, записывать, пропускать, возвращать и помещать символы.** Для обычного консольного ввода основными инструментами являются `std::cin`, `>>`, `get()`, `getline()`, `ignore()` и обработка состояния потока через `clear()`.
