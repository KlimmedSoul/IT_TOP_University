## 🤝 Как внести свой вклад (Contribution)

Репозиторий открыт для улучшений! Если у вас есть выполненные работы, которых здесь еще нет, или вы нашли ошибку и хотите её исправить:

1. Сделайте **Fork** данного репозитория.
2. Создайте новую ветку со своими изменениями.
3. Отправьте **Pull Request** (PR).
4. После проверки модератором ваши материалы будут добавлены в основную ветку!
